# ADR 0004 — Isolamento por Row-Level Security

**Status:** aceito

**Decisão.** Três papéis de banco: dono do schema (migrações), `reforma_app` (aplicação, sujeito à RLS)
e `reforma_ref` (escrita da base de referência). O contexto do tenant é aplicado por
`set_config(..., true)` no início de cada transação. Tarefas agendadas usam funções `SECURITY DEFINER`
que devolvem apenas identificadores.

**Consequências.** Um bug de filtro na aplicação não vaza dados. Inserções que dependem de `RETURNING`
precisam de cuidado (valores padrão calculados no Python; o log de auditoria usa inserção sem
`RETURNING`).
